## Purpose

Design the adapter boundary for evaluating externally produced candidate graphics against reusable graphics-validation contracts.

This milestone defines how candidate evaluation should be shaped later without introducing image generation, real candidate-image processing, or approval automation changes now.

## Scope

```text
- Define the candidate evaluation adapter boundary.
- Define candidate input manifest expectations.
- Define evidence output expectations.
- Preserve contract-driven approval decisions.
- Preserve uncertainty -> needs_review behavior.
- Keep the milestone design-only and gated.
- Update the command reference with new verification commands.
```

## Out of scope

```text
- No image generation.
- No image editing.
- No real candidate image ingestion.
- No computer-vision model integration.
- No generated-candidate approval automation.
- No CLI command for candidate evaluation yet.
```
