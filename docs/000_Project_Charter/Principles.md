# CPE-0000 Guiding Principles

Status: Draft
Version: 0.1

## Principles

1. The specification is the source of truth.
2. AI is never the authority.
3. Renderers are interchangeable.
4. Every requirement should be testable.
5. Validation must be independent from generation.
6. Every failure becomes reusable knowledge.
7. Revisions should be localized whenever possible.
8. Artifacts must be traceable from source to output.
9. Human approval remains explicit for publishable work.
10. The repository is the canonical project memory.

## Design Consequence
ConstraintOS must be built as a constraint-first platform, not as a prompt library or renderer-specific image workflow.
